# SPPS planner V1.0.0

GitHub-ready initial stable standalone SPPS Planner package.

This V1 package is based on the former V1.0.5 clean native UI build and promoted as the GitHub V1 line.

## Build on Windows

Run:

```bat
INSTALL_BUILD_TOOLS_AND_BUILD.bat
```

Outputs:

```text
dist\SPPS_Planner\SPPS_Planner.exe
installer\installer_output\SPPS planner V1.0.0.exe
```
