# SPPS planner V1.0.0

GitHub 업로드용 초기 안정판 SPPS Planner 독립 패키지입니다.

이 V1 패키지는 기존 V1.0.5 clean native UI build를 GitHub용 V1 라인으로 정리한 버전입니다.

## Windows 빌드

아래 파일을 실행하면 됩니다.

```bat
INSTALL_BUILD_TOOLS_AND_BUILD.bat
```

생성 위치:

```text
dist\SPPS_Planner\SPPS_Planner.exe
installer\installer_output\SPPS planner V1.0.0.exe
```
