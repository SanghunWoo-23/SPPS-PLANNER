# SPPS Planner V9.0.0 — Current Development Scope

> **Development source, not a validated Windows installer or production laboratory SOP.**
> See [Current status (KO)](docs/CURRENT_STATUS_KO.md) for supported
> features and the specific limits of the scientific claims.

V9.0.0 retains the existing Project Manager, editable Step 1/2,
Generate/Apply, Materials, Checklist, Workup and stored-project workflows.
The cumulative V9 development adds guarded protected/branched/cyclic theoretical
mass calculations, explicit atom-mapped graph verification, reviewed Auto Plan
chemistry evidence, local/consent-based literature research, multi-sheet
Excel/CSV imports and experimental AI/ML evaluation.

**Theoretical structure or mass outputs are not reaction-feasibility proofs.**
Unsupported residue chemistry and ambiguous reaction connections should
return review/unsupported status, never fabricated predictions.
No real wet-lab independent ML accuracy or native Windows installer
acceptance is claimed for this source package.
