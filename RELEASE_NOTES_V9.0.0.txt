2026-11-24 INTEGRATION, EDC·HCl/NHS AND ML TRUST REFINEMENT (SOURCE ONLY)
- EDC·HCl/NHS is now a named operator-review coupling system for Head-to-tail and Branch; ADD recipe shortcut includes the two separately selected bottles. Existing EDC·HCl/HOBt is preserved.
- The textual aliases EDC-HCl and EDC·HCl map to one review identity without overwriting supplier-specific bottle information. Missing reagent equivalents are never inferred.
- EDC/NHS activation is NOT a validated peptide cyclization SOP: NHS ester hydrolysis, possible N-acylurea byproducts, epimerization and oligomers need review. The linked Yan et al., RSC Adv. 2015 mechanism is polymer-context evidence only, NOT a peptide cyclization benchmark.
- New Loading model builds use grouped cross-validation by run_id / work_item_id / identical input conditions, not random row-based KFold. Models trained before this release are not retroactively relabeled or retrained. At least two independent groups are required.
- Selected Cyclic Review exports independent protected-linear / protected-cyclic / deprotected-cyclic average neutral MW when available. Exact-mass-derived theoretical ESI m/z appears only after RDKit graph crosscheck passes. Never use average MW as exact m/z.
- Disulfide MS output is recomputed from current sequence and Cys positions, not trusted from a stale stored structure snapshot. Unsupported chemistry returns WITHHELD rather than fabricated mass/ions.
- Existing Plan, Materials, Checklist and Excel/CSV/JSON output routes remain in place. Existing official INSTALL_BUILD_TOOLS_AND_BUILD.bat is unchanged; no extra BAT/CMD, placeholder or monkey patch added.
- This is SOURCE ONLY. No native Windows installer acceptance or wet-lab protocol verification has been performed on this revision.
