SPPS Planner V4.0.0 - Completion / Validation Notes
Date: 2026-08-11

Scope
- Completed first-class Loading time (h) and Cleavage time (h) state across Planner input, active peptide item, project/session persistence, ML advisor sync/apply, and calculation/report output.
- Loading/Cleavage time are process conditions only; they do not alter stoichiometric reagent or cocktail amounts.
- Loading ML prediction uses a deterministic RandomForestRegressor only when at least 12 operator-Verified, non-outlier loading records with sufficient target variation exist. Otherwise it falls back to similarity evidence.
- ML prediction is advisory only. Apply never writes a model-generated optimum.
- Loading Apply requires direct 2-CTC/Trityl loading mode, a target loading, and one operator-Verified exact resin + amino-acid historical record. It applies only the actual condition recorded in that source row.
- Cleavage Apply requires one operator-Verified exact-product record with a complete TFA/TIS/H2O condition and no additional/unknown cocktail component. Records with DCM/MC/other unresolved components are evidence-only and cannot be partially applied.
- Parsed records remain evidence-only until explicitly Verified.
- Apply re-runs analysis immediately before writing values, preventing stale recommendations.
- Loading Apply regenerates the normal Planner outputs; Cleavage Apply uses the existing Apply Change workflow.
