Recommendation policy
1. Repeated successful bottle-level historical condition (HISTORICAL CONSENSUS) first.
2. If exact compound consensus is unavailable, repeated category condition may be shown only when the full condition repeats at least twice in the same resin family.
3. A single historical occurrence is not automatically promoted to a recommendation.
4. Reagent identities/eq values from unrelated experiments are not mixed.
5. Global Coupling Apply is enabled only when all current coupling units have evidence and agree on one supported condition.
6. Otherwise per-unit evidence is shown and global Apply remains disabled.

Coupling recommendation coverage
- Amino acids, including D/non-natural bottle-level entries when present in Plan history
- Chemical / label units
- Linkers
- Tags/presets when represented as Plan units
- Reagent 1 such as DIC/HBTU/HATU and equivalent
- Reagent 2 / additive such as HOBt/Oxyma and equivalent
- Base and equivalent
- Coupling solvent
- Coupling time (h)
- Repeat count
- Recorded solvent volume basis where available

Data entry
- Loading result form is prefilled from current Planner loading settings; measured loading remains operator-entered.
- Coupling result form saves yield/purity/failure/doubling outcome to the active peptide Work Item. Current Plan rows and reagent conditions are retained as the evidence features.
- Cleavage result form is prefilled from current Planner sequence/scale/eq/time and, when available, current generated TFA/TIS/water volumes.
- Missing result fields are not fabricated.
