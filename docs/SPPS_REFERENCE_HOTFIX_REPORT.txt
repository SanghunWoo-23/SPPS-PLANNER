Pepforge Public Research Release V2.0.0
SPPS Last Wash + Docking Workbench Full Data Hotfix

Patch focus
1. SPPS Planner final wash logic
   - Last deprotection or terminal chemical/label/tag/cap coupling no longer receives the ordinary post-coupling DMF x2 transition wash.
   - Final rows now go directly to final wash: DMF x3 followed by DCM x3.
   - Applies to free N-terminus final deprotection and terminal Ac/FITC/FAM/Biotin/Pal/Caf/Gal/Nic style modifier rows.

2. Docking Workbench full-data visibility
   - Added Input data full, Results data full, and MD data full buttons.
   - Full-data windows are resizable Toplevel notebooks and keep compact UI panes unchanged.
   - Target summary, affinity summary, PRODIGY-like values, GROMACS/MD-like values, contacts, atom contacts, and MD import summaries remain accessible even when compact panes are crowded.

3. Regression preservation
   - Based on the previous V2.0.0 complete Docking Workbench final package.
   - Retains compound DB MW/density normalization, PyMOL Bridge quick safe export, Docking affinity/MD-style tables, SPPS terminal chemical/label/tag/cap handling, and alias/full-name improvements.

Verification
- Python compile passed for suite_gui/spps_tk_gui.py and suite_gui/docking_workbench_gui.py.
- SPPS GUI smoke tests via xvfb for Ac-EEMQRR-NH2, FITC-EEMQRR-NH2, and EEMQRR-NH2.
- Verified no final-step post-coupling wash rows are generated for terminal modifier rows or final deprotection rows.
- Verified final wash remains DMF x3 then DCM x3.
- Docking Workbench GUI smoke test verified full-data table registry and external-style validation summary.

Version
